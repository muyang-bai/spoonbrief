## 四、本地运行

```bash
cp backend/.env.example backend/.env    # 填 DATABASE_URL / REDIS / SECRET_KEY / ENCRYPTION_KEY / DEEPSEEK_API_KEY / SMTP_*
docker compose up -d --build
# 前端 http://localhost:8080     API 文档 http://localhost:8000/docs
```

生产使用三份 compose 叠加固定镜像版本：
```bash
docker compose -f docker-compose.yml -f docker-compose.frontend-image.yml \
               -f docker-compose.t158-credits.yml up -d
```

## 五、技术栈

Python 3.11 + FastAPI ｜ Celery 5 + Redis 7 ｜ MySQL 8（与 AiLifeOS 共用 `muyang_main`）｜ Vue 3 + Vite ｜ DeepSeek（deepseek-flash）｜ Docker Compose ｜ nginx + Let's Encrypt
