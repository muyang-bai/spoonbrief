## 问题

每天 700+ 条热点，与你相关的不到 10 条，却要花 40 分钟翻。
资讯 App 按热度排、RSS 只聚合、通用 AI 每天把同样的新闻重新总结——**读起来像新的，其实没有新增信息**。

## 我们的答案（链路）

```
订阅方向 → 定时派发 → 19 信源信息池 → 素材筛选
        → 事件级新颖性判定（全新 / 实质进展 / 重复）
        → 无更新时：跳过 或 周期汇总（用户可选）
        → AI 分析师全文（按订阅模板）
        → 决策层：情绪 / 影响分 / 今日行动 / 五维影响
        → 邮件发送（浅色蓝 · 图文 · 原文链接 · 五星信源）
        → 反馈（有用/没用 + 原因）→ 注入下一期
```

## 三个别人没做好的点

1. **只推新增**：同事件多篇报道合并；纯转载、换标题、AI 重述判为重复，不推送
2. **无更新不硬凑**：可选"今天没有值得打扰你的新增"，或改为周期汇总
3. **反馈真的会改变下一期**：负反馈带原因（太浅/太旧/依据不足…），下一期生成时作为约束注入
