# 分析模板（Skill）创建指南

模板 = AI 的角色设定（System Prompt）+ 分析指令（User Prompt 模板）。
创建订阅时选择不同模板，AI 就会以不同身份和分析框架为您生成简报。

## 一、核心概念

| 概念 | 说明 |
|---|---|
| 模板名称 | 一眼看出角色的名字，如「考研政策分析师」「短线情报员」 |
| System Prompt | 告诉 AI 它是谁、什么风格、按什么框架分析 |
| User Prompt 模板 | 分析指令模板，支持 `{content}` 和 `{persona}` 两个变量 |
| 模型 | 该模板使用的模型名（默认 `deepseek-v4-flash`） |
| 温度 | 0-100，越低越严谨、越高越发散（默认 70） |
| 开源 | 勾选后所有用户可见可用；不勾选仅自己可见 |

## 二、两个变量（必须掌握）

- `{content}` —— **热点信息占位符**。系统自动把抓取到的新闻注入到这里。
  模板中必须包含此变量，否则 AI 看不到任何新闻（系统会兜底追加，但建议显式写出）。
- `{persona}` —— **读者画像占位符**。系统自动注入用户在「我的画像」填写的身份与兴趣。
  包含它，AI 才能"以用户视角"分析。

⚠️ 使用**单个**花括号：`{content}`、`{persona}`。不要写成双花括号。

## 三、推荐模板结构（可直接复制）

```
你是一位资深分析师，风格犀利直接、结论先行。

输出三大模块：
1. 白话解读：每条热点用 2-3 句话讲清"是什么、为什么值得关注"
2. 与我相关：结合读者画像，分析这条热点对每个身份的影响与交叉价值
3. 行动建议：3-5 条具体可执行的下一步（有时间、有渠道、有动作）

引用热点必须标注来源编号（如「据[3]报道」），禁止编造。

## 读者画像
{persona}

## 热点信息
{content}
```

## 四、输出规范（硬性要求）

1. 只输出 HTML 正文片段（`<h3>` `<p>` `<ul><li>` `<strong>`），
   **禁止** `<html>` `<head>` `<style>` 等整页结构和任何 CSS
2. 直接输出内容本身，不要先描述"我接下来会输出什么"
3. 引用热点必须标注来源编号，没有依据的内容不要编造
4. 行动建议必须具体可执行

## 五、开源说明

- **勾选「开源此模板」**：所有用户可在「开源模板」页看到、选用、下载您的模板
- **不勾选**：私有模板，仅您自己可见可用
- 官方模板由管理员维护，普通用户不可编辑；自己创建的模板随时可编辑、删除
- 模板支持导出为 `.hotmailskill.json` 文件分享给他人（对方用「导入 Skill」加载）

## 六、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 双花括号 `{{content}}` | 变量注入失败，AI 看不到新闻/画像 | 单花括号 `{content}` |
| 输出整页 HTML + CSS | 邮件排版失控、内容被截断 | 只用语义标签的正文片段 |
| 开场先描述"我将输出…" | 有效内容被浪费 | 直接输出分析内容 |
| 建议写"值得关注" | 无法执行 | 写"X月X日前登录某官网完成Y" |
| 引用不带编号 | 无法溯源 | "据[3]报道" |
