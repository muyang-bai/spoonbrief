## 一、产品概述

**一勺热点 是一款 AI 驱动的个性化情报简报产品**：用户设定关注方向、身份画像与送达时间，系统每 30 分钟从 14 个公开信源采集热点新闻，AI 全局分析师结合用户画像进行两阶段分析（信息抽取 → 全局分析），将热点翻译成「机会 / 风险 / 行动建议」，生成一封可溯源的简报，定时送达用户邮箱。

核心理念一句话：**AI 会出错，我们让它无处可藏**——每一条 AI 结论都挂原始新闻链接，多源交叉验证后才打可信标，把判断权还给用户。

产品已上线稳定运行（Docker 六服务生产部署，含定时调度、失败告警、每日备份），并经历多轮真实用户反馈迭代。

## 三、核心功能

1. **订阅管理**：关注关键词（中英文逗号/空格分隔均支持）、信息类别、时间窗口（今日～近30天）、闹钟式滚轮定时（每天/每周/每月，北京时间）
2. **AI 全局分析**：两阶段流水线生成结合用户画像的定制解读（机会/风险/行动建议），正文引用 [N] 编号与原始新闻一一对应，点击即可溯源
3. **可溯源简报**：每封简报分「AI 全局分析」「与你相关」「今日要闻」三层；每条新闻标注来源、信源可信度（1-10）、多源交叉验证状态、原文链接
4. **定时送达**：北京时间定时推送至邮箱，最多 3 个收件地址；每封含独立退订链接
5. **多源交叉验证**：同事件被多家独立信源报道时自动合并打标，剔除单一信源噪音
6. **画像系统**：多重身份（学生/创业者/投资者/创作者）+ 兴趣标签 + 专业/行业/风险偏好，参与个性化分析
7. **额度与预算管理**：每份简报消耗 1 额度（默认每月 60），订阅级月度上限，超支自动暂停并邮件通知——成本透明可预期
8. **用户自定义 RSS 源**：可添加个人信息源（≤10 个），并入自己的简报
9. **管理后台**：用户管理、信息源管理、官方分析模板、公告、合规文本、注册开关

## 四、AI 的角色与价值（重点）

**AI 不是辅助开发工具，而是产品核心服务本身**：

| AI 能力 | 在服务中的角色 | 对应大赛考核点 |
|---|---|---|
| 信息抽取（Stage 1） | 将候选新闻压缩为带编号的结构化要点，供下游分析与溯源对齐 | 理解信息 |
| 全局分析（Stage 2） | 注入用户画像与订阅关键词，生成机会/风险/行动建议 | 生成内容 |
| 溯源对齐 | 结论引用 [N] 与原始新闻一一绑定，AI 输出可核查 | 辅助判断 |
| 个性化解读 | 同一新闻对不同身份给出不同视角（千人千面） | 创造新体验 |

**AI 核心价值体现**：传统新闻聚合只能"给链接"，AI 摘要工具"不敢信"。本产品让 AI 完成"读→懂→翻译成行动"，并用溯源机制解决 AI 幻觉信任问题——这是 AI 直接参与核心服务、且创造传统技术难以实现体验的直接体现。

**AI 工具来源标注**：简报 AI 分析由 DeepSeek（deepseek-v4 系列）生成，产品内与邮件中均有明确标注；用户可自带 DeepSeek/火山方舟 API Key。

## 五、技术实现思路

**技术栈**：Python 3.11（FastAPI）+ Vue 3（Vite）+ PostgreSQL 16 + Celery 5/Redis 7 + DeepSeek + Docker Compose 生产部署。

**五步流水线**：

1. **数据供给**：每 30 分钟抓取 14 个 RSS 信源 → 信息池（700+ 条滚动）；同事件多源报道通过「15 字指纹 + jieba 分词交集(≥2) + 字符 2-gram Dice(≥0.40)」三级语义归并
2. **个性化匹配**：订阅关键词 + 画像词库对信息池打分（整词命中+5、词元命中+2/+1，≥2 词元计匹配），分出相关层与广度层
3. **AI 两阶段分析**：Stage 1 抽取（max_tokens 4000）→ Stage 2 全局分析（max_tokens 8000，注入画像+关键词），输出清洗与 [N] 引用链接化
4. **溯源与可信**：信源可信度分级（官方 10/权威 9/专业 7/科技 6/社区 4），多源交叉验证打标
5. **定时送达**：cron 表达式 + Celery beat 每 60 秒巡检 → worker 生成 → SMTP 发送；四层防重（10 分钟去重/运行中跳过/24h 过期滚动/任务状态落库）+ watchdog 自愈 + 失败告警邮件

**可靠性**：Docker restart 策略 + 每 5 分钟健康自愈 + 每日 03:00 自动备份（保留 7 份）。

## 六、应用场景示例

**场景 1：考研学生（"上岸信息差"）**
订阅「考研政策，专业扩招，集成电路」→ 每天 8:00 收到简报 → AI 提示"教育部扩大集成电路专业硕士招生，结合你的目标院校建议核实简章"→ 点击 [1] 溯源到官方新闻核对。

**场景 2：AI 行业从业者**
订阅「AI 产品，大模型，新平台」→ 简报推送新平台动态（如"秒哒平台上线"）→ AI 分析其生态机会与竞争格局 → 点引用直达原文深入了解。

**场景 3：投资者**
订阅「黄金，美联储，新能源」→ AI 输出机会/风险两栏 + "不构成投资建议"声明 → 每条结论可溯回财新网等权威信源 + 多源交叉验证标。

## 七、创新点

1. **可溯源 AI 简报**：结论与证据链一一绑定，[N] 引用即原文链接——解决 AI 内容信任问题
2. **订阅制情报闭环**：从"人找信息"到"信息找人"，定时投喂而非一次性问答
3. **千人千面解读**：多重身份画像参与分析，同一新闻不同视角
4. **成本透明可控**：额度体系 + 订阅级预算上限 + 超支自动暂停通知
5. **闹钟式循环滚轮时间选择器**等体验细节（来自真实用户反馈迭代）
