# Local font assets

`InterVariable.woff2` is the official Inter variable font, used for Latin text,
numbers and interface typography. Chinese text uses the native PingFang SC,
Microsoft YaHei UI / Microsoft YaHei or Noto Sans SC fallback configured in
`src/styles/foundation.css`.

Source: https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2

Downloaded: 2026-10-29. License: SIL Open Font License 1.1.
The complete copyright and license notice is included in `Inter-LICENSE.txt`.

The font is served from this project; there is no font CDN request at runtime.
